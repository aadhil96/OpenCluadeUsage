Features

Everything you need at a glance.

Reads Claude Code's local JSONL transcripts directly — no API calls, no account login, no tracking.

⚡

Live session tracking

Rolling 5-hour window matching Anthropic's rate-limit bucket. See exactly when your session resets.

📅

Weekly totals

Rolling 7-day window with a countdown to the next reset. Track your weekly quota at a glance.

🤖

Per-model breakdown

See how much Sonnet, Haiku, and Opus each contributed to your session.

📊

Plan percentage bars

Set your plan (Pro, Max 5×, Max 20×) and watch live percentage bars fill up as you work.

🔄

Auto-refresh on open

Fetches fresh data the instant you click the tray icon. Configurable background poll interval too.

🔒

100% local

Reads files directly from ~/.claude/projects/. Nothing leaves your machine.

How it works

Reads your local transcripts.

Claude Code writes every conversation to JSONL files on disk. ClaudeUsage parses those files directly — no network requests needed.

~/.claude/projects/**/*.jsonl 
{
  "type": "assistant",
  "timestamp": "2025-06-13T10:30:00.000Z",
  "message": {
    "id": "msg_abc123",
    "model": "claude-sonnet-4-6",
    "usage": {
      "input_tokens": 1234,
      "output_tokens": 567,
      "cache_creation_input_tokens": 8900,
      "cache_read_input_tokens": 45000
    }
  }
}

// ClaudeUsage scans every file, deduplicates by message ID,
// aggregates into 5h session + 7d weekly windows, and renders
// the result in a floating panel above your menu bar.

Install

Up in 30 seconds.

Download, drag to Applications, and click the tray icon. That's it.

1

Download the latest release

Grab ClaudeUsage.dmg from the GitHub Releases page.

2

Drag to Applications

Open the .dmg and drag ClaudeUsage.app into your /Applications folder.

3

Bypass Gatekeeper (first launch)

macOS may block the app since it's not notarized. Right-click → Open → Open to allow it. Or run once in Terminal:

xattr -cr /Applications/ClaudeUsage.app
4

Set your plan in Settings

Click the tray icon → gear icon → select your Claude plan (Pro, Max 5×, or Max 20×) to enable percentage bars.
